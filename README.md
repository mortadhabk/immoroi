# Simulateur ROI Immobilier

Frontend React + TypeScript (Vite) pour simuler la rentabilité d'un portefeuille immobilier.

## Démarrage

```bash
npm install
npm run dev
```

Ouvre ensuite l'URL affichée par Vite.

## Features

- CRUD appartements (création, édition, duplication, suppression)
- Calculs ROI (rendements, cashflow, prêt)
- Comparateur multi-appartements
- Graphiques Recharts
- Import/Export JSON
- Sauvegarde LocalStorage
- Onboarding première visite + parcours guidé

## Structure

- `src/models`
- `src/store`
- `src/services/calculations`
- `src/components`
- `src/pages`
- `src/utils/format`
